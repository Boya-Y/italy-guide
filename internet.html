Connessione

上网 · 国内先办好

在中国买好、装好、测好；落地只开数据。旅游 eSIM 多半只有流量、没有 +39 号码。

主推：Airalo（国内买）

为什么选它：App 中英文都有，国内用国际信用卡/部分借记卡可直接买；档位多，适合中国护照游客「出发前安装、落地激活」。Nomad/Holafly/GigSky 也能买，但 Airalo 流程最稳、中文资料最多。

买多少：意大利城际 7–14 天、地图+聊天+偶发视频 → 选 10 GB / 30 天；重度上传/热点 → 20 GB 或按天数选 Unlimited。出发前在官网核对当期价。

  1. 确认手机已解锁且支持 eSIM（设置里搜「蜂窝 / 添加 eSIM」）。
  2. 下载 App：Airalo（iOS / Android）。
  3. 在 App 搜 Italy，或打开购买页选套餐付款。
  4. 付款后点 Install eSIM / 安装（需稳定 Wi‑Fi）；按提示完成后先关掉这张 eSIM 的数据，避免国内误激活。
  5. 设置 → 蜂窝网络：主卡（中国号）保留通话/短信、关闭蜂窝数据；把「蜂窝数据」指到 Airalo；开启「数据漫游」仅对 eSIM。
  6. 落地意大利：打开飞机模式再关 → 开 Airalo 数据 → 测地图 → 再报平安。
推荐动作 起飞前在国内 Wi‑Fi 装好 eSIM；截图保存安装二维码/订单；把本页与急救页加到主屏幕。

备份：中国移动「欧洲多国流量包」

为什么当备份：eSIM 装不上/激活失败时，实体中国卡立刻能上网报平安；日费明显高于 eSIM，不作主力。联通/电信也有国漫日包，出发前在本运营商 App 查「意大利」当日价。

  1. 出发前开通国际漫游。
  2. 中国移动：官网/App 办「欧洲多国流量包」（含意大利），或短信按提示订购；详见漫游页。
  3. 平时：中国卡关数据，只留短信（银行验证码）。
  4. 仅当 eSIM 不可用：打开中国卡数据漫游，用完日包立刻关掉。

备选对比（需要再换时）

  • Nomad：意大利固定 GB 性价比常更好（例 20GB/30天），流程同「国内买→预装」。nomadesim.com/italy-eSIM
  • Holafly：按天数「无限流量」，热点常有日限额，短途猛用可选。esim.holafly.com/esim-italy
  • GigSky：可预装、落地连网激活。gigsky.com · Italy

价格与运营商绑定会变；付款页为准。实体旅游卡（TIM/WindTre 等）可落地机场买，但需护照、排队——不如国内 eSIM 省事。

落地日 3 步

  1. 下飞机 → 开 eSIM 数据（中国卡数据保持关）。
  2. 微信/电话报平安。
  3. 再用地图去机场→市区交通。
