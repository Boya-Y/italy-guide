打电话怎么说

  1. 接通后先报城市：Sono a Roma / Firenze / Milano / Venezia.
  2. 英语最短句：Emergency. I need help. Address: …（读酒店地址或地图大头针）。
  3. 急救：Ambulance please. Someone is hurt / cannot breathe.
  4. 被盗：My bag / passport was stolen. I need a police report (denuncia).
  5. 不会意语就重复 English please；112 常能转英语接线。

去哪：Pronto Soccorso

  1. 医院急诊入口看红字 Pronto Soccorso（急救）。
  2. 危及生命：先打 118 / 112，不要自己开车硬闯。
  3. 能走：地图搜 Pronto Soccorso + 所在城；带护照、保险单、欧盟插头充电宝。
  4. 细节与保险报案步骤见 就医页。
