支付与换钱

主力 = 银联借记卡 + Visa/Mastercard + 少量欧元现金。支付宝/微信当惊喜，不当依赖。

出发前配卡（清单）

  1. 带 1 张银联（62 开头）借记卡：POS 消费 + ATM 取现（取现优先借记卡，信用卡取现贵）。
  2. 带 1 张Visa 或 Mastercard：酒店/租车押金、部分只认国际卡的柜台。
  3. 银行 App 开通境外交易；记下挂失电话；行程可告知发卡行降风控误拒。
  4. 双标卡（银联+Visa/MC）刷卡时：能选通道就选 UnionPay（走银联汇率/优惠）。
推荐动作 落地日先小额刷一笔 + ATM 取 €50–100 测试；失败立刻换备用卡。

ATM 怎么取（步骤）

  1. 优先银行门口机：Intesa Sanpaolo、UniCredit、Poste Italiane（银联称约九成 ATM 可取欧元）。
  2. 找屏幕/机身 UnionPay 银联标志；插卡 → 输 PIN → Withdraw / Prelievo → EUR。
  3. 出现 DCC / 动态货币转换（问是否用人民币记账）：一律选以欧元 € 扣账，拒银行临时高汇率。
  4. 确认前看清手续费提示；银联侧一般不另收 ATM 佣金，但发卡行可能收跨境费——出发前问自家银行。
  5. 避开路边独立小黄机（Euronet 等）除非别无选择；费用常更高。

UniCredit 部分机有中文界面（不保证每台）。单笔/日限额以发卡行为准，可分多笔。

支付宝 / 微信现实

  1. 仅已接入 Alipay+ / 微信境外收单的店能用（旅游区、部分连锁、机场商户更多）。
  2. 收银看到支付宝/微信标或收银员说 Alipay：打开 App 扫 POS 上的码，或出示付款码。
  3. 没标就别问太久——直接刷银联/Visa。
  4. 不能当全国通用；超市、小餐馆、市场摊经常没有。

现金用途

随身 €50–150：咖啡馆小单、公厕、小费、只收现金的小店。大额别换汇摊；用银行 ATM。

被盗刷 / 丢卡

  1. 银行 App 立刻冻卡 → 打发卡行挂失。
  2. 被盗抢：打 112 / 113，要 denuncia 回执给保险。
  3. 备用卡分开放（酒店保险箱 / 另一包）。
